**Section C7**: Relative importance of each factor in admission decision

**Why Critical**: Shows what colleges OFFICIALLY prioritize

- Validates emphasis on character, intellectual curiosity, etc.

## Phase 4: Verification & Cross-Validation (Week 7)

### Task 4.1: Apply Enhanced Formula to All Existing Weights

For each dimension weight currently in database:

1. **Gather 5 Required Sources**:
   - [ ] Institutional source (CDS, mission, strategic plan)
   - [ ] Prompt analysis (already done)
   - [ ] Admissions officer source (interview, blog, book)
   - [ ] Expert/research source (NACAC, former AO, study)
   - [ ] Comparative analysis (peer schools)

2. **Calculate Weighted Score**:
   ```
   Score = (Institutional × 30%) + (Prompt × 25%) +
           (Admissions Officer × 25%) + (Expert × 15%) + (Comparative × 5%)
   ```

3. **Validate Weight Range**:
   - 90-100 score → 30-35% weight
   - 80-89 score → 25-29% weight
   - 70-79 score → 20-24% weight
   - 60-69 score → 15-19% weight
   - 50-59 score → 10-14% weight
   - Below 50 → 5-9% weight

4. **Document Source Chain**:
   - Create table with all 5 sources
   - Show calculation
   - Provide student-facing citation

5. **Mark as Verified**:
   - Update database with ✅ "Fully Verified" stamp
   - Date of verification
   - Who verified (for accountability)
