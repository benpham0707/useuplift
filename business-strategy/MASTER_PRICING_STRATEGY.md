## 🎯 PART 4: ANTI-FRAUD SYSTEM

### 4.1 The Account Farming Problem

**Why 6 Credits Per Analysis**:

```
OLD SYSTEM (5 credits/analysis):
├─ 10 free credits = 2 free analyses
├─ Student farms accounts (email+1@gmail.com trick)
├─ Gets 2 analyses per account × infinite accounts
└─ RESULT: Never converts to paid, you lose money

NEW SYSTEM (6 credits/analysis):
├─ 10 free credits = 1 analysis + 4 messages
├─ Can't get 2nd analysis without buying
├─ Creates conversion trigger (4 credits left, need 6)
└─ RESULT: Must buy to continue
```

---

### 4.2 Fraud Prevention Layers

#### Layer 1: Email Normalization

```typescript
function normalizeEmail(email: string): string {
  let normalized = email.toLowerCase().trim();
  const [localPart, domain] = normalized.split('@');

  if (domain === 'gmail.com' || domain === 'googlemail.com') {
    // Remove dots (gmail ignores them)
    let cleanLocal = localPart.replace(/\./g, '');
    // Remove +tricks
    cleanLocal = cleanLocal.split('+')[0];
    return `${cleanLocal}@gmail.com`;
  }

  return normalized;
}

BLOCKS:
├─ user+1@gmail.com → user@gmail.com (already exists)
├─ user+essay2@gmail.com → user@gmail.com (blocked)
└─ u.s.e.r@gmail.com → user@gmail.com (blocked)

IMPACT: Prevents 40-50% of account farming
```

---

#### Layer 2: Device Fingerprinting

```javascript
// Using Fingerprint.js or similar
const deviceId = await FingerprintJS.load().then(fp => fp.get());

RULE:
├─ Max 2 free accounts per device fingerprint
├─ 3rd attempt → require phone verification or payment
└─ Tracks: browser, OS, screen, timezone, plugins, etc.

IMPACT: Prevents 30-40% more farming (cumulative 70-90%)
```

---

#### Layer 3: IP Rate Limiting

```sql
-- Supabase Edge Function
SELECT COUNT(*)
FROM users
WHERE created_at > NOW() - INTERVAL '24 hours'
  AND signup_ip = $1;

RULE:
├─ Max 3 free signups per IP per day
├─ 4th attempt → require phone verification
└─ VPN detection → flag for review

IMPACT: Catches persistent fraudsters
```

---

#### Layer 4: Behavioral Analysis

```
SUSPICIOUS PATTERNS:
├─ Account created → 1 analysis → abandoned (no workshop)
├─ Same essay text across multiple accounts (plagiarism check)
├─ Multiple accounts from same payment method
└─ Extremely fast usage (bot-like behavior)

ACTION:
├─ Auto-flag for manual review
├─ Require email verification (slow down farming)
└─ Limit to free tier (no paid option until verified)
```

---

### 4.3 Fraud Economics

```
WITHOUT FRAUD PREVENTION:
├─ 40% of users farm multiple accounts
├─ Average 3 accounts per fraudster
├─ Cost: 3 × $0.40 = $1.20 per fraudster
├─ 1,000 users → 400 fraudsters → $480 wasted

WITH FRAUD PREVENTION:
├─ 5% manage to create 2 accounts
├─ Cost: 2 × $0.28 = $0.56 per fraudster
├─ 1,000 users → 50 fraudsters → $28 wasted
└─ SAVINGS: $452 per 1,000 users (94% reduction)
```
