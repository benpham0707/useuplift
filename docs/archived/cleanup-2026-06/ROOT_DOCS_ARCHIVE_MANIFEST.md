## Method (zero-breakage verification)

A deterministic repo-wide reference graph was built (`git ls-files` → substring
scan of all 2,874 tracked text files) BEFORE any move. Findings:

- The **only** root docs with real code/config/CI references are the 11 keepers
  (allowlist + verified `src/` citations). All 176 moved files had **zero**
  hard dependencies — only soft doc/prose cross-links.
- **15** live files mentioned a moved doc; **9** were false positives (basename
  collisions like `INDEX.md` inside `*_INDEX.md`). The **6** real prose/comment
  references were rewritten to the new archive paths (see below).
- The untracked agent-memory dir was swept clean of references.
