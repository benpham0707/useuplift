## Common Issues & Solutions

### Issue: "Source provides contradictory information"

**Solution**:
1. Weight by source reliability (Primary > Secondary > Tertiary)
2. Favor more recent sources (2020+ > 2015-2019 > pre-2015)
3. Favor more specific sources (essay-specific > general admissions)
4. Document contradiction in database notes
5. Use weighted average if both credible

### Issue: "CDS Section C7 not available for this college"

**Solution**:
1. Check college's Institutional Research (IR) office website
2. Search for "[College] Common Data Set 2024"
3. Email IR office requesting CDS
4. If truly unavailable, redistribute Institutional weight (30%) across other 4 sources:
   - Mission/Strategic Plan only: 30%
   - Prompt: 25% → 30%
   - Admissions Officer: 25% → 28%
   - Expert: 15% → 17%
   - Comparative: 5% → 5%
5. Document "CDS unavailable" in notes

### Issue: "Cannot verify quote is exact - source behind paywall"

**Solution**:
1. Check if institutional library access available
2. Search for quote in Google Books preview
3. Check Internet Archive (archive.org) for book preview
4. If unverifiable, rate reliability lower (✅ instead of ✅✅)
5. Note "quote unverified - paywall" in source entry

### Issue: "Verification score suggests different weight than current database"

**Solution**:
1. Calculate score following exact formula
2. Map score to weight range per guidelines
3. If recommended weight differs from current by >5%:
   - Document adjustment in WEIGHT_ADJUSTMENTS_SUMMARY.md
   - Explain rationale based on new evidence
   - Update weight in database
   - Ensure all dimensions still sum to 100%
4. If differs by <5%, consider keeping current for consistency

### Issue: "Research provides 4 sources instead of required 5"

**Solution**:
1. Mark as "Partially Verified" (⚠️) instead of "Fully Verified" (✅)
2. Integrate 4 available sources using modified formula:
   - Redistribute 5th source weight proportionally
   - Example: If missing Comparative (5%), add 1.25% to each other source
3. Add to "pending research" list in SOURCE_GATHERING_ROADMAP.md
4. Note which source is missing in database entry

### Issue: "Expert source lacks clear credentials"

**Solution**:
1. Research author background (LinkedIn, college website, book bio)
2. If no credentials found, rate as ✅ (Moderate) not ✅✅
3. Use lower score (50-60 instead of 70-85) in verification calculation
4. Note credential uncertainty in source entry
5. Consider finding additional expert source to strengthen

## Quick Reference: Minimum Standards

**To be considered "Fully Verified" (✅✅✅)**:
- ✅ 5+ independent sources
- ✅ All quotes exact (not paraphrased)
- ✅ CDS Section C7 included (or documented why unavailable)
- ✅ Admissions officer quote from Dean/Director level
- ✅ Expert source with clear credentials
- ✅ Verification score 70+/100
- ✅ All URLs tested and accessible
- ✅ Weight implications clear and specific

**To be considered "Partially Verified" (⚠️)**:
- ✅ 3-4 sources
- ✅ Quotes mostly exact
- ⚠️ Some elements missing but substantial evidence available
- ✅ Verification score 50-69/100
- ✅ Documented plan to complete verification

**Insufficient for Integration (❌)**:
- Fewer than 3 sources
- Paraphrased quotes without access to originals
- Verification score <50/100
- Major contradictions unresolved
- No clear connection to dimensional weights
