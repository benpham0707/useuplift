## System Query Guide

### How to Resolve Student Questions

**Step 1: Identify Context**
- What grade is the student?
- What are their current achievements?
- What is their specific question?

**Step 2: Select Primary Resource**
- Timeline questions → 7.1
- Activity progression → 7.2
- Deadline questions → 7.3
- College questions → 7.7
- Essay questions → 7.8
- Testing questions → 7.11
- Financial questions → 7.12
- Interview questions → 7.14
- Post-decision questions → 7.15

**Step 3: Cross-Reference**
- Pull relevant data from activity databases
- Check red flag documents if concerns
- Connect advice to spike development

### Example Query Resolution

**Query:** "I'm a junior who wants to major in CS at Stanford. How should I prepare?"

**System Resolution:**
1. **7.1 (Junior section):** Peak achievement year priorities
2. **7.2 (USACO pathway):** Target Gold or Platinum division
3. **7.3 (Calendar):** USACO contest dates in Dec, Jan, Feb, US Open
4. **7.5 (Programs):** RSI application deadline January
5. **7.7 (Stanford):** REA Nov 1, no DI tracking, values intellectual vitality
6. **7.11 (Testing):** Target 1500+ SAT, test optional but strong scores help
7. **7.13 (CS):** CS is competitive at Stanford, show interdisciplinary interest
8. **7.14 (Interviews):** Stanford alumni interviews, prepare for intellectual vitality questions
9. **STEM_OLYMPIADS:** USACO division context and progression
10. **HACKATHONS_CS:** Hackathon and project context

**Query:** "I got deferred from my ED school. What should I do?"

**System Resolution:**
1. **7.15 (Deferral section):** Immediate action plan, LOCI template
2. **7.8 (Updates):** What new content to send
3. **7.7 (Other schools):** RD applications to submit
4. **7.12 (Financial):** Considerations for RD schools

## Integration Flow

### Evaluation → Counseling Pipeline

```
INPUT: Student Profile
    ↓
EVALUATION (What IS)
├── Activity databases → Tier assessment
├── Red flag detection → Risk identification
└── Academic analysis → Strength/weakness
    ↓
COUNSELING (What to DO)
├── Grade-appropriate guidance (7.1)
├── Activity-specific pathways (7.2)
├── Timeline integration (7.3)
├── Application strategy (7.7-7.15)
└── Recovery if needed (7.6)
    ↓
OUTPUT: Personalized Action Plan
```
